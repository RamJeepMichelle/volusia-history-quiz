# Volusia History Quiz

**A retro QBasic trivia game about Volusia County, Florida.** Ten random questions (from a bank of 15) about New Smyrna's 1768 colony, the Ponce de Leon Inlet Lighthouse, Mary McLeod Bethune, NASCAR's founding, Bike Week, Jackie Robinson in Daytona Beach and more. Every answer comes with a "Did you know?" fact.

**Play it in your browser:** https://ramjeepmichelle.github.io/volusia-history-quiz/

Built by **Jeep Michelle**, a Jeep and Ram commercial fleet specialist in New Smyrna Beach, Volusia local history buff and Halifax Historical Society volunteer.

## Two versions

| File | What it is |
| --- | --- |
| `VOLUSIA.BAS` | The original game in QBasic. Runs in QBasic 1.1, QuickBASIC 4.5, [QB64](https://qb64.com) and [QBJS](https://qbjs.org) |
| `index.html` | A web version with the same questions and a classic blue DOS look |
| `questions.py` | The question bank; `build.py` generates both versions from it |

## Run the QBasic version

- **In a browser:** open [qbjs.org](https://qbjs.org), paste the contents of `VOLUSIA.BAS` and click Run.
- **On Windows, Mac or Linux:** install the free [QB64](https://qb64.com), open `VOLUSIA.BAS` and press F5.
- **In real DOS or DOSBox:** `QBASIC /RUN VOLUSIA.BAS`
